Portal Admin Tenant

Panduan Alur Kerja Owner Photobooth

Petunjuk langkah demi langkah untuk mengelola akun, membuat event, dan menghubungkan Google Drive.

1

Registrasi Akun Baru

Buka halaman pendaftaran, masukkan **Nama Usaha**, **Email**, dan **Password**. Akun baru otomatis berstatus PENDING.

2

Verifikasi Langganan

Hubungi Super Admin untuk pembayaran sewa. Setelah diverifikasi, status akun berubah menjadi AKTIF dan portal siap digunakan.

3

Atur Event & Frame Foto

Buat event baru, unggah *frame PNG*, dan tempelkan **Link Google Drive** khusus acara agar foto tamu otomatis tersimpan rapi.

4

Cetak QR Code Event

Buka detail event lalu cetak atau tampilkan QR Code di booth acara. Tamu tinggal memindai QR tersebut untuk mulai berfoto.
